Recall the formula for Margin of Error:
ME = z* · (σ / √n)
Notice how sample size n is underneath a square root in the denominator!

What happens to the margin of error in a confidence interval when sample size n is quadrupled?

A
It remains the same
B
It is halved
C
It is doubled

It is reduced by a factor of 4

Correct Deduction!

Because the Margin of Error is inversely proportional to √n, quadrupling the sample size n → 4n results in √(4n) = 2√n, which cuts the margin of error exactly in half (1/2).
