## 📌 Core Concept & Mental Model
**Recursive Production Rules, Hierarchical Parse Trees, Stack-Augmented Finite State Transitions, Binary Normal Forms, and Dynamic Programming Substring Parsing** govern Context-Free Languages (Type 2 in the Chomsky Hierarchy), compiler front-end syntax analysis, and non-regular language recognition (Noam Chomsky 1956, Anthony Oettinger 1961, John Cocke, Daniel Younger, & Tadao Kasami 1965, Michael Sipser Chapter 2):
* **1. Context-Free Grammars (CFG - 4-Tuple):**
  - Formally defined as $G = (V, \Sigma, R, S)$ where $V$ is non-terminals, $\Sigma$ is terminals ($V \cap \Sigma = \emptyset$), $R \subseteq V \times (V \cup \Sigma)^*$ is production rules, and $S \in V$ is the start symbol.
  - **Derivations:** Leftmost vs Rightmost derivations.
  - **Ambiguity:** A grammar is *ambiguous* if there exists a string $w \in L(G)$ with **$\ge 2$ distinct parse trees** (or leftmost derivations).
  - **Inherent Ambiguity:** A language $L$ is inherently ambiguous if *every* CFG generating $L$ is ambiguous (e.g. $L = \{a^i b^j c^k \mid i=j \lor j=k\}$).
* **2. Chomsky Normal Form (CNF) & CYK Parsing:**
  - **CNF Invariant:** Every production rule has the exact form:
    $$\mathbf{A \to BC \quad (\text{Two non-terminals})} \qquad \text{or} \qquad \mathbf{A \to a \quad (\text{Single terminal})}$$
    (and optionally $S \to \varepsilon$ if $\varepsilon \in L$).
  - **The 4 Normalization Conversion Steps:**
    1. Create new start symbol $S_0 \to S$.
    2. Eliminate $\varepsilon$-rules ($A \to \varepsilon$).
    3. Eliminate unit rules ($A \to B$).
    4. Convert remaining rules into binary non-terminal pairs and single terminals.
  - **The CYK Parsing Algorithm ($O(n^3 \cdot |G|)$):**
    - Dynamic programming triangular table $T[i, j]$ containing all variables $A$ that generate substring $w[i \dots j]$:
      $$\mathbf{T[i, j] = \bigcup_{k=i}^{j-1} \Big\{ A \mid A \to BC \in R, \ B \in T[i, k], \ C \in T[k+1, j] \Big\}}$$
* **3. Pushdown Automata (PDA - 7-Tuple):**
  - Formally defined as $M = (Q, \Sigma, \Gamma, \delta, q_0, z_0, F)$:
    - $Q$: States; $\Sigma$: Input alphabet; $\Gamma$: Stack alphabet; $z_0 \in \Gamma$: Initial stack symbol; $F \subseteq Q$: Final states.
    - Transition function: $\mathbf{\delta: Q \times (\Sigma \cup \{\varepsilon\}) \times \Gamma \to \mathcal{P}(Q \times \Gamma^*)}$.
  - **Equivalence Theorem:** A language is generated by a CFG $\iff$ It is recognized by a Pushdown Automaton ($L(\text{CFG}) = L(\text{PDA})$)!
* **4. Deterministic PDAs (DPDA) & Closure Properties:**
  - **DPDA (Deterministic Context-Free Languages - DCFL):**
    - At most one transition allowed from any state configuration. Recognizes strict subset of CFLs (the grammar basis for $LR(k)$ compiler parsers!).
  - **CFL Closure Laws:**
    - **CLOSED Under:** **Union** ($S \to S_1 \mid S_2$), **Concatenation** ($S \to S_1 S_2$), **Kleene Star** ($S \to S_1 S \mid \varepsilon$), and **Intersection with Regular Languages** ($L_{\text{CFL}} \cap L_{\text{REG}}$).
    - **NOT CLOSED Under:** **Intersection** ($L_1 \cap L_2$) and **Complement** ($\overline{L}$).

## 🔑 Best Known Study Methodologies & Learning Framework

### 1. The Stack Matching Mental Model
* A stack allows counting up (pushing) and matching back down (popping) to check balances (e.g. $a^n b^n$, matching parentheses).
* Two independent counts (e.g. $a^n b^n c^n$) fail because a single stack cannot track multiple independent counters.
