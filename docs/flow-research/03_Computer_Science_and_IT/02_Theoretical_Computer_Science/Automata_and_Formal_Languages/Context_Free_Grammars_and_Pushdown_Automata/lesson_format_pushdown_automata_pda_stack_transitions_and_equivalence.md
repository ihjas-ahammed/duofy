## 🎯 Pedagogical Blueprint & Objective
Guide students through the 7-tuple formal definition, non-deterministic stack transition dynamics, and computational equivalence of Pushdown Automata (Anthony G. Oettinger 1961; Marcel-Paul Schützenberger 1963; Michael Sipser Chapter 2; John E. Hopcroft et al.): master the **7-Tuple PDA Specification ($M = (Q, \Sigma, \Gamma, \delta, q_0, z_0, F)$)** where $\Gamma$ is the stack alphabet and $z_0$ is the initial bottom-of-stack marker, decode **Transition Function Syntax ($\mathbf{a, b \to c}$ meaning: read input $a$, pop stack symbol $b$, push string $c$)**, trace stack counting mechanics recognizing classic non-regular context-free languages (e.g. $L = \{w w^R \mid w \in \{0, 1\}^*\}$ and $L = \{a^n b^n \mid n \ge 0\}$), contrast **Acceptance by Final State ($T(M)$)** with **Acceptance by Empty Stack ($N(M)$)**, and prove the **Equivalence Theorem ($\mathbf{L(\text{CFG}) \equiv L(\text{PDA})}$)**.

## 🤖 LLM Prompt Generation Rules & Directives

1. **Slide 1 (`theory`):** State Pushdown Automata (Oettinger 1961; Schützenberger 1963; Sipser Chapter 2):
   - **The 7-Tuple Definition:** $M = (Q, \Sigma, \Gamma, \delta, q_0, z_0, F)$ where:
     - $Q$: Finite set of states; $\Sigma$: Input alphabet; $\Gamma$: Stack alphabet.
     - $q_0 \in Q$: Start state; $z_0 \in \Gamma$: Initial bottom-of-stack sentinel symbol.
     - $F \subseteq Q$: Set of accepting/final states.
     - $\mathbf{\delta: Q \times (\Sigma \cup \{\varepsilon\}) \times (\Gamma \cup \{\varepsilon\}) \to \mathcal{P}(Q \times (\Gamma \cup \{\varepsilon\}))}$.
   - **Transition Notation ($a, b \to c$):**
     - When machine reads input character $a$ (or $\varepsilon$) and stack top is $b$, it transitions to the next state, pops $b$, and pushes string $c$ onto the stack!
   - **The Master Equivalence Theorem (Chomsky-Schützenberger 1963):**
     $$\mathbf{\text{A language } L \text{ is generated by a CFG} \iff \mathbf{L \text{ is recognized by a Pushdown Automaton (PDA)}}}$$
2. **Slide 2 (`ordering`):** Provide 5 steps of a non-deterministic PDA recognizing even palindromes $L = \{w w^R \mid w \in \{0, 1\}^*\}$: (1) start in initial state q0 with bottom marker $ on top of the stack, (2) read the first half of the input string, pushing each binary character onto the stack while remaining in state q0, (3) execute a non-deterministic epsilon-transition to state q1, guessing that the exact midpoint of the palindrome has been reached, (4) in state q1, read the remaining input symbols, matching each character with the popped top of the stack, (5) upon seeing input end and bottom marker $, transition to accepting state q2 and accept the string!
3. **Slide 3 (`matching`):** Pair 4 PDA formal entities (Stack Alphabet Gamma, Bottom Sentinel z_0, Transition a, b -> c, Empty Stack Acceptance N(M)) with their definitions.
4. **Slide 4 (`fill_in_blank`):** Single sentence blank testing recall that a Pushdown Automaton is augmented with an infinite-capacity LIFO stack. Plain text only.
5. **Slide 5 (`quiz`):** Quiz on the computational limit of a single stack: Why can a single-stack Pushdown Automaton recognize $L_1 = \{a^n b^n \mid n \ge 0\}$ but fails completely to recognize the language $L_2 = \{a^n b^n c^n \mid n \ge 0\}$? (Because when verifying $a^n b^n$, the PDA pushes $n$ tokens onto the stack during the $a$'s and pops them during the $b$'s; once the $b$'s finish, **the stack has been completely exhausted (popped to empty)**, leaving **zero remaining memory to count or verify whether the subsequent sequence of $c$'s also contains exactly $n$ characters**).
