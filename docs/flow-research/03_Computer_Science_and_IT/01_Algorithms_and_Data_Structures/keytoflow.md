# Key to Flow: Algorithms and Data Structures

**Subject Area:** `03_Computer_Science_and_IT / 01_Algorithms_and_Data_Structures`

---

## 📌 Core Concept & Mental Model
Algorithms and Data Structures are the foundational building blocks of computation. Data structures organize data for efficient access and modification, while algorithms define unambiguous step-by-step procedures to solve computational problems.

---

## 🔑 Best Known Study Methodologies & Learning Framework

### 1. The Core Taxonomy
* **Data Structures:** Arrays, Linked Lists, Stacks, Queues, Hash Tables, Binary Search Trees (AVL, Red-Black), Heaps/Priority Queues, Trie, Graphs, Disjoint-Set Union (DSU).
* **Algorithm Design Paradigms:**
  1. **Brute Force & Backtracking:** N-Queens, Sudoku solver, Subsets generation.
  2. **Divide and Conquer:** MergeSort, QuickSort, Binary Search.
  3. **Greedy Algorithms:** Kruskal/Prim MST, Dijkstra, Activity Selection, Huffman Coding.
  4. **Dynamic Programming (DP):** Overlapping subproblems + Optimal substructure. (Knapsack, LCS, LIS, Matrix Chain Multiplication).
* **Graph Algorithms:** BFS/DFS, Topological Sort, Shortest Paths (Dijkstra, Bellman-Ford, Floyd-Warshall), Max Flow (Ford-Fulkerson, Edmonds-Karp).

### 2. Time & Space Complexity Analysis
* **Asymptotic Notation:** $O(g(n))$ (Upper bound), $\Omega(g(n))$ (Lower bound), $\Theta(g(n))$ (Tight bound).
* **Master Theorem:** $T(n) = a T(n/b) + f(n)$ for divide-and-conquer recurrences.

### 3. Top Recommended Resources
* **The Algorithms Bible ("CLRS"):** *Introduction to Algorithms* by Cormen, Leiserson, Rivest, Stein.
* **Problem Solving & Coding Interviews:** *Cracking the Coding Interview* by Gayle Laakmann McDowell OR LeetCode.
* **Visualization Tool:** VisuAlgo.net (Interactive algorithm animations!).
