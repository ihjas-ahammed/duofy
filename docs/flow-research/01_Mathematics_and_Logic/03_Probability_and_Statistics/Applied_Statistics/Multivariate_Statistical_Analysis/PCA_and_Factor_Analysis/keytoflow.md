## 📌 Core Concept & Mental Model
**Dimensionality Reduction & Latent Variable Modeling** simplify complex $p$-dimensional multivariate observations $\mathbf{x} \in \mathbb{R}^p$ while preserving maximal information:
* **Principal Component Analysis (PCA / Karl Pearson 1901, Harold Hotelling 1933):**
  A deterministic, descriptive linear transformation finding orthogonal projection directions $\mathbf{w}_1, \dots, \mathbf{w}_p$ that maximize sample variance:
  $$\mathbf{w}_1 = \operatorname{argmax}_{\|\mathbf{w}\|=1} \operatorname{Var}(\mathbf{w}^T \mathbf{x}) = \operatorname{argmax}_{\|\mathbf{w}\|=1} \mathbf{w}^T \mathbf{\Sigma} \mathbf{w} \implies \mathbf{\Sigma} \mathbf{w}_1 = \lambda_1 \mathbf{w}_1$$
  *(Eigenvectors of the sample covariance/correlation matrix $\mathbf{\Sigma} = \mathbf{V} \mathbf{\Lambda} \mathbf{V}^T$).*
* **Exploratory Factor Analysis (EFA / Charles Spearman 1904, Louis Thurstone 1947):**
  A generative probabilistic model explaining correlations via $k \ll p$ unobserved **latent common factors** $\mathbf{f}$:
  $$\mathbf{x} - \mathbf{\mu} = \mathbf{\Lambda} \mathbf{f} + \mathbf{\epsilon}, \qquad \operatorname{Cov}(\mathbf{f}) = \mathbf{I}_k, \quad \operatorname{Cov}(\mathbf{\epsilon}) = \mathbf{\Psi} = \operatorname{diag}(\psi_1, \dots, \psi_p)$$
  $$\mathbf{\Sigma} = \mathbf{\Lambda} \mathbf{\Lambda}^T + \mathbf{\Psi} \quad (\text{Partitioning into Common vs Unique Variance})$$

## 🔑 Best Known Study Methodologies & Learning Framework

### 1. PCA vs Factor Analysis Fundamental Dichotomy
| Dimension | Principal Component Analysis (PCA) | Factor Analysis (FA) |
| :--- | :--- | :--- |
| **Objective** | Data compression / Total variance maximization | Latent construct discovery / Covariance structure |
| **Model** | Linear combination of observed variables $z_k = \mathbf{w}_k^T \mathbf{x}$ | Observed variables generated by factors $x_i = \sum \lambda_{ij} f_j + \epsilon_i$ |
| **Variance Partition** | Treats $100\%$ of total variance ($h_i^2 \equiv 1$) | Splits into **Communality** $h_i^2 = \sum \lambda_{ij}^2$ and **Specific Variance** $\psi_i$ |

### 2. Component Retention Rules & Scree Plots
* **Kaiser-Guttman Criterion:** Retain components with eigenvalues $\lambda_k > 1.0$ (for standardized correlation matrices).
* **Cattell's Scree Test:** Identify the "elbow" point where the scree slope flattens into residual rubble.
* **Proportion of Explained Variance:** $\text{PVE}_k = \frac{\lambda_k}{\sum_{j=1}^p \lambda_j} = \frac{\lambda_k}{p}$.

### 3. Factor Rotations for Simple Structure (Thurstone)
* **Orthogonal Varimax Rotation (Henry Kaiser, 1958):** Rotates factor axes rigidly (preserving $90^\circ$ orthogonality) to maximize variance of squared loadings $\sum \operatorname{Var}(\lambda_{ij}^2)$, driving loadings toward $\pm 1$ or $0$.
* **Oblique Promax / Oblimin Rotation:** Allows factors to correlate ($\operatorname{Cov}(\mathbf{f}) = \mathbf{\Phi}$), reflecting real-world latent interactions.
