## 🎯 Pedagogical Blueprint & Objective
Train students to construct the **Borel $\sigma$-Algebra** $\mathcal{B}(\mathbb{R}) = \sigma(\text{open sets})$, define a **Random Variable** as a $(\mathcal{F}, \mathcal{B})$-**Measurable Function** $X: \Omega \to \mathbb{R}$ whose pre-images $X^{-1}(B) \in \mathcal{F}$, prove that verifying $X^{-1}((-\infty, x]) \in \mathcal{F}$ is sufficient, and understand why non-measurable sets (Vitali sets) necessitate $\sigma$-algebras.

## 🤖 LLM Prompt Generation Rules & Directives

1. **Slide 1 (`theory`):** State the definition of the Borel $\sigma$-Algebra: $\mathcal{B}(\mathbb{R}) = \sigma(\mathcal{T})$ is the smallest $\sigma$-algebra containing all open subsets $\mathcal{T}$ of $\mathbb{R}$. State the Definition of a Random Variable: A mapping $X: \Omega \to \mathbb{R}$ is a **Random Variable** if it is $(\mathcal{F}, \mathcal{B}(\mathbb{R}))$-measurable: for every Borel set $B \in \mathcal{B}(\mathbb{R})$, the pre-image $X^{-1}(B) = \{\omega \in \Omega \mid X(\omega) \in B\} \in \mathcal{F}$. State the Generator Criterion Theorem: $X$ is a random variable if and only if $\{\omega \in \Omega \mid X(\omega) \le x\} = X^{-1}((-\infty, x]) \in \mathcal{F}$ for all $x \in \mathbb{R}$.
2. **Slide 2 (`concept_pieces`):** Deconstruct how all interval types generate $\mathcal{B}(\mathbb{R})$: (1) start with rays $(-\infty, x]$, (2) open ray $(-\infty, x) = \bigcup_{n=1}^\infty (-\infty, x - 1/n]$ is in $\mathcal{B}$, (3) closed ray $[x, \infty) = (-\infty, x)^c$ is in $\mathcal{B}$, (4) bounded open interval $(a, b) = (-\infty, b) \cap [a, \infty)^c = (-\infty, b) \cap (a, \infty)$ is in $\mathcal{B}$, (5) every open set $U \subset \mathbb{R}$ is a countable union of open intervals, proving that $\sigma(\{(-\infty, x] \mid x \in \mathbb{R}\}) = \mathcal{B}(\mathbb{R})$.
3. **Slide 3 (`matching`):** Pair 4 generator collections ($\{(a, b)\}$, $\{(-\infty, x]\}$, $\{[a, b]\}$, Compact subsets) with their generated $\sigma$-algebra $\mathcal{B}(\mathbb{R})$.
4. **Slide 4 (`fill_in_blank`):** Single sentence blank testing recall that to prove $X$ is a random variable, it suffices to show that the pre-image of every ray $(-\infty, x]$ is measurable. Plain text only.
5. **Slide 5 (`quiz`):** Quiz on why probability theory requires $\sigma$-algebras instead of assigning probabilities to all subsets $2^\Omega$: (Vitali's 1905 theorem proved that using the Axiom of Choice, there exist subsets of $[0, 1]$ that cannot be assigned any translation-invariant, countably additive probability measure without creating mathematical contradictions).
