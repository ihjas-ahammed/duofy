## 🎯 Pedagogical Blueprint & Objective
Introduce the **Von Neumann Ordinal Hierarchy** ($\alpha = \{\beta \mid \beta < \alpha\}$), understand the classification into **Successor Ordinals ($\alpha + 1 = \alpha \cup \{\alpha\}$)** and **Limit Ordinals ($\lambda = \bigcup_{\beta < \lambda} \beta$)**, master the 3-step proof principle of **Transfinite Induction**, and formulate **Transfinite Recursion** on the class of all ordinals $\mathbf{On}$.

## 🤖 LLM Prompt Generation Rules & Directives

1. **Slide 1 (`theory`):** State the definition of Von Neumann Ordinals (John von Neumann, 1923): An ordinal $\alpha$ is a transitive set that is strictly well-ordered by the set membership relation $\in$:
   $$\alpha = \{\beta \in \mathbf{On} \mid \beta < \alpha\} = \{\beta \in \mathbf{On} \mid \beta \in \alpha\}$$
   - Base Ordinal: $0 = \emptyset$
   - Successor Ordinal: $\alpha + 1 = S(\alpha) = \alpha \cup \{\alpha\}$ ($1 = \{0\}, 2 = \{0, 1\}, 3 = \{0, 1, 2\}$)
   - Smallest Infinite Limit Ordinal: $\omega = \{0, 1, 2, \dots\} = \mathbb{N}$
   - General Limit Ordinal: An ordinal $\lambda \ne 0$ with no immediate predecessor: $\lambda = \bigcup_{\beta < \lambda} \beta = \sup_{\beta < \lambda} \beta$.
   State Transfinite Induction: To prove property $P(\alpha)$ for all $\alpha \in \mathbf{On}$, it suffices to show: (1) Base Case $P(0)$, (2) Successor Case: $P(\alpha) \implies P(\alpha + 1)$, (3) Limit Case: $(\forall \beta < \lambda, P(\beta)) \implies P(\lambda)$.
2. **Slide 2 (`ordering`):** Provide 5 steps proving that any non-empty set of ordinals $S \subseteq \mathbf{On}$ contains a unique least element under $\in$: (1) pick any element $\alpha_0 \in S$, (2) if $\alpha_0 \cap S = \emptyset$, then $\alpha_0$ is the minimum element of $S$, (3) if $\alpha_0 \cap S \ne \emptyset$, consider the set $A = \alpha_0 \cap S$, (4) since $\alpha_0$ is an ordinal, it is well-ordered by $\in$, so $A \subseteq \alpha_0$ has a least element $\mu \in A$, (5) verify $\mu \in S$ and no element in $S$ is strictly smaller than $\mu$, proving every non-empty set of ordinals has a minimum.
3. **Slide 3 (`matching`):** Pair 4 ordinals ($0$, $3$, $\omega$, $\omega + 1$) with their exact set definitions ($\emptyset$, $\{0, 1, 2\}$, $\{0, 1, 2, \dots\}$, $\omega \cup \{\omega\}$).
4. **Slide 4 (`fill_in_blank`):** Single sentence blank testing recall that limit ordinals are generated by taking the union of all strictly smaller ordinals. Plain text only.
5. **Slide 5 (`quiz`):** Quiz on the Burali-Forti Paradox (Cesare Burali-Forti, 1897): Why cannot the collection of all ordinals $\mathbf{On}$ be a set in ZFC set theory? (Because if $\mathbf{On}$ were a set, it would itself be a transitive set well-ordered by $\in$, making $\mathbf{On}$ an ordinal, which implies $\mathbf{On} \in \mathbf{On} \implies \mathbf{On} < \mathbf{On}$, a direct contradiction! Thus $\mathbf{On}$ is a proper class).
