## 📌 Core Concept & Mental Model
Set Theory serves as the axiomatic foundation of modern mathematics. Zermelo-Fraenkel Set Theory with the Axiom of Choice (**ZFC**) defines all mathematical objects (numbers, functions, manifolds) purely as sets.

---

## 🔑 Best Known Study Methodologies & Learning Framework

### 1. ZFC Axiom Architecture
* **ZFC Axioms:** Extensionality, Null Set, Pairing, Union, Power Set, Infinity, Replacement, Regularity (Foundation), Axiom of Choice (AC).
* **Ordinals ($\alpha$) & Cardinals ($\kappa$):**
  * **Ordinals:** Well-ordered sets representing transfinite order types ($0, 1, 2, \dots, \omega, \omega+1, \dots, \omega_1$).
  * **Cardinals:** Measures of size ($|\mathbb{N}| = \aleph_0 < |\mathbb{R}| = 2^{\aleph_0}$).
* **Axiom of Choice Equivalence:** AC $\iff$ Well-Ordering Theorem $\iff$ Zorn's Lemma.
* **Continuum Hypothesis (CH):** $2^{\aleph_0} = \aleph_1$. Gödel proved CH is consistent with ZF (Constructible Universe $L$), and Paul Cohen proved $\neg\text{CH}$ is consistent using **Forcing**!

### 2. Top Recommended Resources
* **Gold Standard Reference:** *Set Theory* by Thomas Jech.
* **Introductory & Rigorous:** *Classic Set Theory* by Derek Goldrei.
* **Forcing & Independence:** *Set Theory: An Introduction to Independence Proofs* by Kenneth Kunen.
