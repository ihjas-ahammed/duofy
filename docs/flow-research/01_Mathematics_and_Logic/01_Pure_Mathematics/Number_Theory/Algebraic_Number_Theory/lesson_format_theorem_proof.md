# Duofy Reusable Lesson Format: Algebraic Number Theory - Theorem & Proof Derivation

**Target Topic:** `01_Mathematics_and_Logic / 01_Pure_Mathematics / Number_Theory / Algebraic_Number_Theory`  
**Lesson Format Type:** `theorem_proof`  
**Architectural Rule:** EXACTLY 5 SLIDES PER LESSON. Active Recall & Practice-First Pedagogy.

---

## 🎯 Pedagogical Blueprint & Objective
Guide students through foundational proofs in algebraic number theory: Finiteness of Class Number via Minkowski's Geometry of Numbers, Dirichlet's Unit Theorem, and Unique Ideal Factorization.

---

| Slide # | Slide Function | Duofy Slide Type | Target Cognitive State | Output Data Fields Required |
