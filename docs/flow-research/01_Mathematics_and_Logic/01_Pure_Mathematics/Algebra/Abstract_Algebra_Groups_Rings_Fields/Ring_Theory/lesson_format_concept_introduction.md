# Duofy Reusable Lesson Format: Ring Theory - Concept Introduction & Definition

**Target Topic:** `01_Mathematics_and_Logic / 01_Pure_Mathematics / Algebra / Abstract_Algebra_Groups_Rings_Fields / Ring_Theory`  
**Lesson Format Type:** `concept_introduction`  
**Architectural Rule:** EXACTLY 5 SLIDES PER LESSON. Active Recall & Practice-First Pedagogy.

---

## 🎯 Pedagogical Blueprint & Objective
Introduce fundamental Ring Theory concepts (Rings, Ideals, Maximal/Prime Ideals, Quotient Rings $R/I$) by grounding formal algebraic axioms in generalized arithmetic mental models ("collapsing elements of ideal $I$ to zero").

---

## 📐 5-Slide Sequential Flow Table

| Slide # | Slide Function | Duofy Slide Type | Target Cognitive State | Output Data Fields Required |
| :---: | :--- | :--- | :--- | :--- |
| **Slide 1** | Formal Ring / Ideal Definition | `theory` | Encoding (Phase A) | `content` (Markdown + LaTeX) |
| **Slide 2** | Quotient Ring & Mental Model Flow | `concept_pieces` | Encoding (Phase A) | `content` (Sequential bullets) |
| **Slide 3** | Ideal & Structure Property Matching | `matching` | Discrimination (Phase B) | `content`, `matchPairs` (3-6 pairs) |
| **Slide 4** | Key Ideal Condition Fill-in-the-Blank | `fill_in_blank` | Recognition (Phase B) | `content`, `blankAnswer`, `blankDistractors` |
| **Slide 5** | Ideal Type Discrimination Quiz | `quiz` | Production (Phase C) | `content`, `options` (4 options, 1 correct) |

---

## 🤖 LLM Prompt Generation Rules & Directives

1. **Slide 1 (`theory`):** State formal definition of Ring $(R, +, \cdot)$ or Ideal $I \subseteq R$ using display LaTeX. Double-escape backslashes (`\\subseteq`, `\\in`).
2. **Slide 2 (`concept_pieces`):** Deconstruct quotient ring $R/I$ into 4 intuitive sequential points explaining how $R/I$ sets all elements $x \in I$ to $0 \pmod I$.
3. **Slide 3 (`matching`):** Pair 4 ring properties (`left`) with their exact mathematical conditions (`right`).
4. **Slide 4 (`fill_in_blank`):** Single sentence blank testing recall of Maximal vs Prime ideal quotient outcomes. **STRICT RULE (Rule 11):** Plain text, NO LaTeX `$`.
5. **Slide 5 (`quiz`):** Multiple choice question asking whether a specific quotient ring is an Integral Domain or a Field.
