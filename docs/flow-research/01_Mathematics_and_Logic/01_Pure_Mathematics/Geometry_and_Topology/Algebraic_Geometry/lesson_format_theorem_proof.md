# Duofy Reusable Lesson Format: Algebraic Geometry - Theorem & Proof Derivation

**Target Topic:** `01_Mathematics_and_Logic / 01_Pure_Mathematics / Geometry_and_Topology / Algebraic_Geometry`  
**Lesson Format Type:** `theorem_proof`  
**Architectural Rule:** EXACTLY 5 SLIDES PER LESSON. Active Recall & Practice-First Pedagogy.

---

## 🎯 Pedagogical Blueprint & Objective
Guide students through core algebraic geometry proofs: Hilbert's Basis Theorem (every ideal in $k[x_1, \dots, x_n]$ is finitely generated), Weak Nullstellensatz, and Bézout's Theorem for plane curves.

---

## 📐 5-Slide Sequential Flow Table

| Slide # | Slide Function | Duofy Slide Type | Target Cognitive State | Output Data Fields Required |
| :---: | :--- | :--- | :--- | :--- |

| **Slide 2** | Proof Strategy & Leading Terms Order | `ordering` | Discrimination (Phase B) | `content`, `orderItems` (3-6 steps) |
