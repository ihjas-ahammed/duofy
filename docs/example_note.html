Section 1

Binary Operations

1. Theory & Core Concepts

The transition from elementary school arithmetic to high school algebra involves using letters to represent unknown numbers and studying basic equations. Abstract algebra takes the next step in abstraction: not only are the variables unknown, but the actual operations involved may also be unknown. We study sets equipped with binary operations possessing properties similar to addition and multiplication.

Some Words of Warning: Two Essential Conditions

When attempting to define a binary operation $\ast$ on a set $S$, we must guarantee that:

  1. Everywhere Defined & Well-Defined: Exactly one element of $S$ is assigned to each possible ordered pair of elements of $S$. If no element is assigned to some pairs, $\ast$ is not everywhere defined. If ambiguity exists, $\ast$ is not well-defined.
  2. Closure: For each ordered pair of elements of $S$, the assigned element must reside back inside $S$. If this is violated, $S$ is not closed under $\ast$.

Induced Operations: If $\ast$ is an operation on $S$ and $H$ is a subset of $S$, $H$ is closed under $\ast$ if $a \ast b \in H$ for all $a, b \in H$. In this case, restricting $\ast$ to $H$ gives the induced operation of $\ast$ on $H$.

2. Definitions & Formal Proofs

1.1 Definition (Binary Operation) Definition

A binary operation $\ast$ on a set $S$ is a function mapping $S \times S$ into $S$. For each $(a, b) \in S \times S$, we denote the element $\ast((a, b))$ of $S$ by $a \ast b$.

1.4 Definition (Closure & Induced Operation) Definition

Let $\ast$ be an operation on $S$ and let $H$ be a subset of $S$. The subset $H$ is closed under $\ast$ if for all $a,b \in H$ we also have $a \ast b \in H$. In this case, the operation on $H$ given by restricting $\ast$ to $H$ is the induced operation of $\ast$ on $H$.

1.11 & 1.12 Definitions (Commutativity & Associativity) Definition

• An operation $\ast$ on a set $S$ is commutative if $a \ast b = b \ast a$ for all $a, b \in S$.

• An operation $\ast$ on a set $S$ is associative if $(a \ast b) \ast c = a \ast (b \ast c)$ for all $a, b, c \in S$.

1.13 Theorem (Associativity of Function Composition) Theorem

Let $S$ be a set and let $f, g,$ and $h$ be functions mapping $S$ into $S$. Then composition of functions is associative: \[ f \circ (g \circ h) = (f \circ g) \circ h \]

Proof.

To show these two functions are equal, we must show that they give the same assignment to each $x \in S$. Computing we find that \[ (f \circ (g \circ h))(x) = f((g \circ h)(x)) = f(g(h(x))) \] and \[ ((f \circ g) \circ h)(x) = (f \circ g)(h(x)) = f(g(h(x))), \] so the same element $f(g(h(x)))$ of $S$ is indeed obtained. $\blacksquare$

1.14 Definition (Identity Element) Definition

Let $S$ be a set with binary operation $\ast$. If $e \in S$ has the property that for all $a \in S$, \[ a \ast e = e \ast a = a, \] then $e$ is called an identity element for $\ast$.

1.15 Theorem (Uniqueness of Identity Element) Theorem

A set $S$ with binary operation $\ast$ has at most one identity element.

Proof.

We need to show that there cannot be two different identity elements. To do this, we assume that both $e$ and $e'$ are identities and show that $e = e'$.

Consider the element $e \ast e'$. Since $e$ is an identity, $e \ast e' = e'$. But $e \ast e' = e$ because $e'$ is also an identity. Therefore $e = e'$. $\blacksquare$

1.17 Definition (Inverse Element) Definition

If $\ast$ is an operation on the set $S$ and $S$ has an identity element $e$, then for any $x \in S$, an inverse of $x$ is an element $x' \in S$ such that: \[ x \ast x' = x' \ast x = e \]

3. Examples, Counterexamples & Pitfalls

1.3 Example: Matrix Addition $M(\mathbb{R})$

Not an Operation

Let $M(\mathbb{R})$ be the set of all matrices with real entries. Usual matrix addition $+$ is not an operation on $M(\mathbb{R})$ because $A + B$ is undefined for matrices having different numbers of rows or columns.

1.5 Example: Nonzero Reals $\mathbb{R}^*$

Not Closed

Usual addition $+$ on $\mathbb{R}$ does not induce an operation on $\mathbb{R}^*$ (nonzero reals) because $2 \in \mathbb{R}^*$ and $-2 \in \mathbb{R}^*$, but $2 + (-2) = 0 \notin \mathbb{R}^*$.

1.6 Example: Squares $H = \{n^2 \mid n \in \mathbb{Z}^+\}$

• Under Addition: Not Closed ($1^2 = 1, 2^2 = 4 \in H$, but $1+4=5 \notin H$).
• Under Multiplication: Closed ($r=n^2, s=m^2 \implies rs = (nm)^2 \in H$).

1.8–1.10 Examples: Custom Operations

• $a \ast b = \min(a,b)$: Commutative & Associative (programmed into GPS systems).
• $a \ast' b = a$: Associative, but Non-commutative ($2 \ast' 3 = 2 \neq 3$).
• $a \ast'' b = \min(a,b) + 2$: Non-associative ($(2 \ast'' 5) \ast'' 9 = 6 \neq 4 = 2 \ast'' (5 \ast'' 9)$).

1.26 Example: Formula $a \ast b = a / b$

• On $\mathbb{Q}$: Invalid ($2 \ast 0 = 2/0$ is undefined).
• On $\mathbb{Q}^*$: Valid Operation.
• On $\mathbb{Z}^+$: Not Closed ($1 \ast 2 = 1/2 \notin \mathbb{Z}^+$).

1.27–1.30 Examples: Function & Set Cases

• $f \ast g = f/g$ on $F$: Not Closed ($g(x)=0$ creates undefined points).
• Function greater than $f$ and $g$: Not Well-Defined (Vague; ambiguous assignment).
• Shortest person taller than $a, b$: Not Everywhere Defined (Fails if $a$ or $b$ is the tallest person).
