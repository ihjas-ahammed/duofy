# What's New in v26.9.1 (Build 2127090101)

- **Multi-File LaTeX Studio & Workspace File Manager**:
  - Full multi-file project support allowing cross-file references (`\include{...}`, `\input{...}`, `\bibliography{...}`, custom `.sty` macros).
  - Mobile-first **Slide-Out Navigation Drawer** for managing workspace files with extension-aware icons, `[MAIN]` root compilation badge, Set Root, Rename, and Delete actions.
  - **VS Code-Style Top File Tabs Bar** with real-time active tab indicators, individual tab close buttons (`x`), and instant file creation (`+`).
  - **Multi-File Online TeX Live Engine**: Seamlessly packages and validates all workspace files into `https://latex.ytotech.com/builds/sync` for complete BibTeX citation resolution and multi-part document builds.
  - **Enhanced Offline PDF Compiler**: Built-in fallback engine with automated BibTeX citation parser (`\cite{key}` ➔ `[1]`), reference list formatting, and recursive `\include`/`\input` multi-file content inlining.
  - **Multi-File Starter Presets**: Academic Paper (BibTeX), Multi-Chapter Report, Hello World, Math & Physics Formulas, Beamer Slides, and Resume / CV.
  - **BibTeX Syntax Highlighting**: Added keyword tokenization (`@article`, `@book`, `journal`, etc.) and `%` comment highlighting in `CodeHighlighter`.
  - **Hot Reload Resiliency**: Added state reassembly hooks and eliminated build-phase controller mutations to prevent recursive widget rebuild loops.

- **Reel-like View & Navigation Improvements**:
  - Added dedicated **Reel-like View** screen button across module and section headers.
  - Simplified document action button labels from "Open Module Notes (PDF)" to "Module Notes".
