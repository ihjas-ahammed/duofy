# What's New in v26.8.27 (Build 2127082701)

- **Online LaTeX Compiler via HTTP POST**: Replaced URL-length-restricted GET requests with JSON POST payloads to `https://latex.ytotech.com/builds/sync`, enabling compilation of arbitrarily large, multi-page LaTeX documents, books, and complex mathematical papers without URL truncation.
- **Explain Error with AI (LaTeX IDE)**: Integrated automated AI diagnosis and 1-tap correction directly in the LaTeX Studio error dialog. The AI inspects both the source code and pdflatex log to provide line-by-line root causes, clear markdown explanations, and an "Apply Fix to Editor" action.
- **Fixed LaTeX Syntax Highlighting**: Disabled quote-based string parsing for LaTeX/TeX files in `CodeHighlighter` so mathematical derivatives ($f'(x)$, $f''(x)$) and LaTeX quotation marks (`` ``...'' ``) are no longer misidentified as strings.
- **Lesson Formats Optimization & 10-Cap**: Streamlined default and generated lesson formats to the top 10 pedagogical formats, enforcing strict non-programming subject filtering to prevent coding slide types (`program`, `try_yourself`) in academic subjects.
- **Interactive Programming Course Selector**: Added an interactive toggle card and programming language selector (Python, JavaScript, C/C++, Java, SQL, Rust, Go, etc.) in the Course Generator window with explicit AI prompt directives.
- **Pedagogical Slide Prompt Refinements**: Removed startup/objective overview slides to jump straight into subject matter on slide 1, and enforced concise, question-only descriptive slides with zero embedded answers.
- **Comprehensive Learning App Theme Research**: Published in-depth whitepaper and design token specification (`docs/learning_app_theme_research.html`) exploring cognitive load theory, color psychology, and modern EdTech design systems.
